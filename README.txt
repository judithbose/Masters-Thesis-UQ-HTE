This repository contains the R code for the master's thesis "Uncertainty Quantification for Heterogeneous Treatment Effects: Doubly Robust Tree-Based Learning with and without Missing Data". In addition, the simulated data and the results of the simulations are included.

The R code is located in the "Code" folder. The scripts whose names begin with 0 are used for the simulation studies with complete data. Scripts beginning with 1 are used for the simulation study with missing covariate data. Scripts beginning with 2 are used to generate tables or graphs for the analysis.

The "Data" folder contains the simulated data, each separated according to the data-generating mechanism. The "Results" folder contains the tables and graphs used for the analysis in the master’s thesis.
